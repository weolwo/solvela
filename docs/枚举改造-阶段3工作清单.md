改造过程中发现：项目里围绕枚举的**三套辅助设施当初都假定了字段是 Integer**，
字段一换成枚举就会静默出错。三处都已修好并配了回归用例：

| 设施 | 不修的后果 | 修在哪 |
| --- | --- | --- |
| MyBatis 默认 `EnumTypeHandler` | 按枚举名映射，读 int 值直接抛 `No enum constant XxxEnum.10` | `MybatisPlusConfig#enumTypeHandlerCustomizer` |
| `@EnumSerialize` | `xxxDesc` 静默变 null，页面上一列空白，接口照样 200 | `EnumSerializer` |
| `@CheckEnum` | 校验恒失败，**接口恒返回 400** | `EnumValidator` |

> 第三条不是假想：`TicketStatusEnum` 的 javadoc 里记着「曾让『按中奖状态筛选购彩记录』恒返回 400」。
