# 已泄露 / 极常见密码表（P3 ③）。
#
# 🔴 这里【只收能过强度校验的那些】。MemberPasswordPolicy 已经要求 8-32 位、
#    同时含字母与数字，所以 "123456"、"password"、"qwerty" 这类根本进不来 ——
#    把它们写进来只是让这个文件看起来很长。
#    真正危险的是「看起来合规、其实人人都在用」的那一批：password1 / Passw0rd! / Aa123456。
#
# 格式：一行一个，大小写不敏感（加载时统一转小写），# 开头是注释，空行忽略。
# 判断是 O(1) 的集合查找，所以这个表长到几万行也不影响注册接口的耗时。
#
# 来源：公开泄露库里长期占据前列的那些（RockYou、Have I Been Pwned 的 top 列表、
# 各家年度「最差密码」榜单）的交集，再筛掉过不了强度校验的。
# ⚠️ 它不是全量库 —— 全量要么是几 GB 的本地文件，要么是一次外部调用（见 §12.9）。
# 这一份挡住的是实际被撞得最多的那批，而不是「所有泄露过的密码」。
